# Implantacao do Scrum no App Organiza+ - Agenda 10 TI I (Recuperacao)

Atividade de recuperacao da Agenda 10 da disciplina Tecnologias da Informacao I.

## Descricao

Roteiro explicativo e infografico sobre a aplicacao prática do framework Scrum para solucionar os desafios de uma startup no desenvolvimento do aplicativo "Organiza+":
- Gestao de alteracoes constantes de escopo do cliente;
- Entregas de incrementos funcionais a cada duas semanas;
- Nivelamento e alinhamento de equipe mista de 5 desenvolvedores.

## Estrutura de Arquivos

- `Rodrigo_Ag10_REC_TI.docx`: relatorio e roteiro estruturado no formato oficial da entrega.
- `infografico_scrum.png`: infografico visual sintetizando papeis, fluxo da Sprint e gestao de backlog.
- `interacao_ia.png`: registro do dialogo e co-criacao com a Inteligencia Artificial.
- `infografico.html`: codigo-fonte do infografico.
- `interacao_ia.html`: transcricao visual do dialogo com a IA.
- `gerar_roteiro.py`: script de geracao do documento docx.
- `test_validacao.py`: testes automatizados de integridade dos arquivos e artefatos.

## Como Executar os Testes

```bash
python test_validacao.py
```
